Privacy

How this site handles your information

Last updated 23 November 2026

This page explains what AppContinuity collects on this website and how that information is used. It is a plain description of current practice, not legal advice.

What the fit-check form collects

The “Book a fit check” form asks for your name and email address. It also asks which parts of the stack apply (a React app wrapped with Capacitor, Supabase Auth, and Stripe subscriptions on the web). You may also share an optional app link and a short note about where paid access drifts today. A hidden honeypot field is included only to discourage automated spam; it is not meant for people to fill in.

That information is used to reply about whether your stack matches the scope, and to continue a written conversation about next steps if it does. It is not used for advertising. If the form is temporarily switched to a waitlist because an Integration is already booked, the same fields are used to email you when the next opening is available.

What the checklist signup collects

The entitlement checklist and its PDF are free to use without an email. If you optionally ask to be emailed a copy, the form collects your name, email address, and your confirmation that you want the PDF and short follow-up emails about the checklist. A hidden honeypot field is included only to discourage automated spam; it is not meant for people to fill in.

That information is used to send the PDF link and a few short follow-up emails about this stack. It is not used for advertising. You can stop those follow-ups anytime with the unsubscribe link at the bottom of each email (it opens the unsubscribe page), with your email app’s unsubscribe button, by replying “stop” to the message, or by emailing contact@appcontinuity.com. We stop sending within 48 hours, usually the same day.

The unsubscribe page sends only the email address you confirm, through the same FormSubmit form service described below, so we can mark that address as unsubscribed. We keep that record so we do not email you again.

How the forms are sent

When you submit the fit-check form, the optional checklist signup, or the unsubscribe page, the browser posts it to FormSubmit (formsubmit.co), which delivers the submission so it can be answered or fulfilled. A copy is also sent to contact@appcontinuity.com, and the Reply-To on that notification is set to the email address you entered so a reply goes to you. FormSubmit’s own terms and privacy policy apply to that delivery step.

Email

Questions, fit-check follow-ups, and optional checklist follow-ups use contact@appcontinuity.com. Outgoing mail from that address, including a short confirmation after a fit-check request and (when that sequence is enabled) the checklist PDF link, is sent with Resend. If you write to that address directly, the message is handled as ordinary business email so we can reply.

Hosting

This website is hosted on GitHub Pages. GitHub may process standard server and CDN request data (such as IP address and user agent) as part of serving the site. See GitHub’s own privacy documentation for that processing.

Cookies, analytics and ads

This site’s own code does not set cookies, does not use local storage or session storage for tracking, and does not load advertising or analytics scripts. There is no AppContinuity tracking pixel. Optional sound on the homepage is controlled in the page session only and is not stored.

AppContinuity does not sell personal data collected through this site, and does not run ads on it.

Client work

If you later hire AppContinuity, repository access, vendor dashboards and related project materials are handled under the written scope for that engagement, separate from this public website form.

Requests

To ask what we hold from a fit-check, a checklist signup, or an email thread, or to ask that it be updated or deleted, email contact@appcontinuity.com. We will reply using that same address.
