Privacy

How this site handles your information

Last updated 9 November 2026

This page explains what AppContinuity collects on this website and how that information is used. It is a plain description of current practice, not legal advice.

What the fit-check form collects

The “Book a fit check” form asks for your name and email address. You may also share an optional app link and a short note about where paid access drifts today. A hidden honeypot field is included only to discourage automated spam; it is not meant for people to fill in.

That information is used to reply about whether your stack matches the scope, and to continue a written conversation about next steps if it does. It is not used for advertising.

How the form is sent

When you submit the form, the browser posts it to FormSubmit (formsubmit.co), which delivers the submission so it can be answered. FormSubmit’s own terms and privacy policy apply to that delivery step.

Email

Questions and fit-check follow-ups use contact@appcontinuity.com. Outgoing mail from that address is sent with Resend. If you write to that address directly, the message is handled as ordinary business email so we can reply.

Hosting

This website is hosted on GitHub Pages. GitHub may process standard server and CDN request data (such as IP address and user agent) as part of serving the site. See GitHub’s own privacy documentation for that processing.

Cookies, analytics and ads

This site’s own code does not set cookies, does not use local storage or session storage for tracking, and does not load advertising or analytics scripts. There is no AppContinuity tracking pixel. Optional sound on the homepage is controlled in the page session only and is not stored.

AppContinuity does not sell personal data collected through this site, and does not run ads on it.

Client work

If you later hire AppContinuity, repository access, vendor dashboards and related project materials are handled under the written scope for that engagement, separate from this public website form.

Requests

To ask what we hold from a fit-check or email thread, or to ask that it be updated or deleted, email contact@appcontinuity.com. We will reply using that same address.
